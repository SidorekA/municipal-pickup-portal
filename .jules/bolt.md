## $(date +%Y-%m-%d) - Fix N+1 queries when using properties spanning Prefetch objects
**Learning:** In Django, when iterating over a `Prefetch` query from a property (e.g. `fraction_type.schedules.all()`) inside a loop over objects fetched with `.prefetch_related('waste_bins__waste_fraction__fraction_type')`, the prefetch string must exactly match the depth of the relations needed. Missing `__schedules` at the end of the prefetch string will cause Django to execute a new query for each `.all()` call, leading to a severe N+1 problem. This occurred in `core/views.py` and `pickups/tasks.py` calling `get_next_pickup_date`.
**Action:** Always verify that the `prefetch_related` string is deep enough to cover *all* related lookups performed during loop iteration, especially when calling utility functions that iterate over related objects. Use `__schedules` or the equivalent deepest relationship required.
